# EventEase Booking System

## Description

EventEase Booking System is an ASP.NET Core MVC application designed for managing events, venues, and bookings. The application includes Azure Blob Storage integration for image management, booking validation features, search functionality, and deployment to Microsoft Azure App Service.

## Setup Instructions

1. Download or clone this repository.
2. Rename:

   appsettings.example.json

   to:

   appsettings.json

3. Update the `DefaultConnection` string in `appsettings.json` with your database connection details.
4. Configure Azure Blob Storage settings if required.
5. Open the solution in Visual Studio.
6. Restore NuGet packages.
7. Build and run the application.

## Features

- Venue Management
- Event Management
- Booking Management
- Booking Search and Filtering
- Booking Validation Rules
- Azure Blob Storage Image Upload and Storage
- Create, Read, Update and Delete (CRUD) Operations
- Azure App Service Deployment
- Enhanced Booking Summary View

## Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server / Azure SQL Database
- Azure Blob Storage
- Azure App Service
- C#
- Razor Views
- HTML, CSS, and Bootstrap
