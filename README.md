# EventEase Booking System

## Description

EventEase Booking System is an ASP.NET Core MVC application for managing event bookings and venue management.

## Setup Instructions

1. Download or clone this repository.

2. Rename:

appsettings.example.json

to:

appsettings.json

3. Update the DefaultConnection string in appsettings.json with your database connection details.

4. Open the solution in Visual Studio.

5. Build and run the application.

## Features

- Venue Management
- Event Management
- Booking Management
- Create, Read, Update and Delete (CRUD) operations

## Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server / Azure SQL Database
- C#
- Razor Views
